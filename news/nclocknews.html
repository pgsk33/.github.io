N Clock: coming soon

2026-04-20

N Clock Closed Beta 3_

The third major update for the N Clock closed beta is now rolling out to testers. This update focuses heavily on core reliability, ensuring your alarms trigger even under difficult conditions like device reboots.

Patch Notes

  • Direct Boot Support: Enabled directBootAware for all core components. Alarms will now function after a reboot even before you unlock your phone.
  • Storage Migration: Refactored AlarmDatabase to use Device Protected Storage, migrating existing data from Credential Encrypted storage safely.
  • Database Improvements: Added formal migrations (v1-v4) and enabled schema exporting for better stability.
  • Next Occurrence Logic: Enhanced AlarmEntity to more accurately calculate trigger times for both repeating and one-time alarms.
  • Auto-scheduling: Updated AlarmReceiver to handle post-trigger logic (re-scheduling or deactivating) automatically.
  • Timer Notifications: Refactored TimerService to allow swiping away notifications, adding "Stop", "Reset", and "Dismiss" actions.
  • Battery Optimization: Reduced AlarmService timeout and WakeLock duration from 2 hours to 10 minutes.
  • Conflict Resolution: Fixed PendingIntent conflicts by using unique alarm IDs as request codes.
